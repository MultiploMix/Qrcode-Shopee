BIPADOR UNIVERSAL V32 — EAN SEM CADASTRO OBRIGATÓRIO DE VARIAÇÕES

ATUALIZAÇÃO: envie index.html, sw.js, manifest.webmanifest, icon.svg e logo-multiplo-mix.png para a mesma pasta do GitHub Pages. CSV e LEIA-ME são auxiliares.

1. Cada cor com EAN diferente: cadastre EAN + SKU COMPLETO para conferência automática. Não precisa cadastrar cores separadamente.
2. Se o EAN tiver somente o SKU BASE (por exemplo WJ-211), não precisa cadastrar cores: ao escanear, o aplicativo exibe a variação exigida pela etiqueta e pede CONFIRMAÇÃO VISUAL explícita, antes de contabilizar. Essa conferência é registrada como visual, pois dois EANs diferentes vinculados à mesma família não provam qual é cada cor.
3. Quando um EAN é compartilhado por várias cores, mantenha as variações do catálogo e selecione a cor observada.
4. QR Code com SKU completo continua com conferência automática.

Não apague o Safari: o catálogo e histórico ficam no armazenamento local. Faça backup do catálogo antes de atualizar.

Valide primeiro no iPhone com pedidos de teste.
